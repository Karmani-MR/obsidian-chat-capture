# Linking beats filing

Folders force every note into exactly one place, but most ideas belong to several topics at once. Links let a note live in many contexts simultaneously, so the useful question when saving a note becomes "what does this connect to?" rather than "where does this go?"

This vault still uses a few folders — but only for a note's **stage** (fleeting, literature, permanent), never for its **topic**. Topics live in maps and links.
