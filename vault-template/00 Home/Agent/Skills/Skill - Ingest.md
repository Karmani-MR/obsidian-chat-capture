# Skill - Ingest

File a new document, deck or source into the right place with links.

## Steps
1. Find the owning hub (course Materials note, project, or map).
2. Put the file in the matching numbered subfolder; add a link line to the hub; superseded versions go to `Older versions`.
3. For readings with a date, add a `[due::]` task to the course Prep note.

## Rules
Follow [[AGENTS]]. Append, don't overwrite. List every note touched.
