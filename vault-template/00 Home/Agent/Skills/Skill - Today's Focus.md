# Skill - Today's Focus

Pick today's top three from Top of Mind, deadlines and the calendar.

## Steps
1. Read [[Top of Mind]], [[Monthly Calendar]] tasks due in the next 3 days and today's events in [[Weekly Calendar]].
2. Write `## Top 3 today` into today's daily note (create it from the Daily Note template if missing).
3. Flag anything overdue in one line each.

## Rules
Follow [[AGENTS]]. Append, don't overwrite. List every note touched.
