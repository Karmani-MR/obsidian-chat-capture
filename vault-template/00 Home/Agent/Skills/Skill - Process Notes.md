# Skill - Process Notes

Turn fleeting notes into literature or permanent notes.

## Steps
1. For each `status: inbox` fleeting note, decide: literature, permanent, project task, or discard (propose discard, never delete).
2. Draft the new note in `01 Fleeting/AI Drafts` with links to a map; set the original to `status: processed` only when approved.

## Rules
Follow [[AGENTS]]. Append, don't overwrite. List every note touched.
